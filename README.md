# Puissance 4 — version 1

Première version du jeu, avec une interface en console et une interface graphique Pygame.

## Prérequis

- Python 3.10 ou une version ultérieure
- Pygame pour lancer la version graphique

Installation de Pygame :

```powershell
python -m pip install pygame
```

## Lancer le jeu

Depuis ce dossier :

```powershell
python Puissance4_Console.py
```

Pour l’interface graphique :

```powershell
python Puissance4_pygame.py
```
